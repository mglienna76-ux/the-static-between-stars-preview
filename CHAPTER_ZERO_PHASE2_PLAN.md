# Chapter Zero — Phase 2 implementation plan
Contract: CHAPTER_ZERO_SPEC_V1.md, approved October 21, 2026.
Branch: chapter-zero-phase2. Original main is frozen.
Status: authorized, implementation not yet certified.

## Milestone A — Deterministic state foundation
- Versioned state schema and migration.
- Pure command resolver for core verbs and canonical IDs.
- Validated route/access/knowledge graph.
- Atomic transition and idempotent action IDs.
- Explicit action outcomes, including nonmutating failures.
- Unit tests for movement, Mercer choice, bulletin, Gabriel aliases, and retries.

## Milestone B — Story and object contracts
- Five location registries with all approved interactables.
- NPC presence, dialogue topics and bounded memory.
- M/V/A nodes awarded only from verified outcome evidence.
- Convergence and three ending predicates.
- No softlocks: refusal, avoidance, denial and time expiry paths.

## Milestone C — Presentation and AI
- All seven views from canonical state.
- AI only for intent interpretation when deterministic grammar fails, and for narration of approved outcomes.
- Safe fallback prose on AI outage; never show internal diagnostics.
- Static cues computed from verified events.

## Milestone D — Release qualification
- Fresh/restore UI smoke tests.
- Three full ending playthroughs.
- 100 seeded varied-command sequences.
- Desktop and mobile manual playthrough.
- GitHub green, matching Vercel READY, and human acceptance before any promotion.

## Change controls
No unreviewed changes to original main, no automatic production promotion, no addition of Day 0 or other playable characters.
